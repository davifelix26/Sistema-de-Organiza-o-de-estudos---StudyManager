# Mini sistema de organização de estudos - StudyManager v1
O StudyManager é um sistema desenvolvido em Python para ajudar estudantes a organizar tarefas acadêmicas e planejar sessões de estudo através do terminal.  A primeira versão será simples e focada na lógica do sistema. Conforme novos conhecimentos forem adquiridos, o projeto poderá ser expandido com novas funcionalidades.

O principal motivo desse mini sistema ser desenvolvido, foi por motivos de prática em lógica de programação, estrutura de dados, funções, laços de repetição e criatividade. Conforme o conhecimento do programador for avançando, o projeto poderá ser de boa utilidade.

Suas funcionalidades são: Adicionar tarefa, visualizar tarefa, remover tarefa e concluir tarefas.
Também temos a parte de gerenciar suas sessões de estudos, marcando um horário e o dia em que o usuário irá estudar e definindo seu objetivo para cada estudos.
